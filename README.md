# ☕ 카페·베이커리 리뷰 텍스트 분석을 통한 고객 경험 요인 및 맞춤형 매장 추천

## 🔗Link
https://seongnae-cafe-recommendation.streamlit.app

## 📌 프로젝트 소개

서울시 강동구 성내동 카페·베이커리 리뷰 데이터를 수집하여 고객 경험 요인을 분석하고, 사용자 선호도를 기반으로 맞춤형 카페를 추천하는 프로젝트입니다.

---

## 🎯 프로젝트 목적

카페 선택 시 개인마다 중요하게 생각하는 요소가 다르다는 점에 주목하여, 리뷰 텍스트 분석을 통해 고객 경험 요인을 도출하고 카페별 특성을 분석합니다.

이를 기반으로 사용자의 선호도와 가장 유사한 카페를 추천하는 시스템을 구현합니다.

---

## 📊 데이터

- 카페명
- 작성일

## 🔍 분석 과정

1. 데이터 수집
2. 데이터 전처리
3. 탐색적 데이터 분석
4. 키워드 분석
5. TF-IDF 분석
6. LDA 토픽 모델링
7. 고객 경험 요인 도출
8. 카페별 고객 경험 프로필 생성
9. 맞춤형 카페 추천

- 불용어 제거
- TF-IDF
- LDA Topic Modeling
- Cosine Similarity

## ☕ 고객 경험 요인

1. 커피·음료 경험
2. 디저트·베이커리 경험
3. 공간·분위기 경험

---

## 💻 추천 시스템

사용자가 중요하게 생각하는 다음 요소를 입력합니다.

- ☕ 커피·음료
- 🥐 디저트·베이커리
- 🏠 공간·분위기

사용자 선호도와 카페별 고객 경험 프로필 간의 Cosine Similarity를 계산하여 가장 적합한 성내동 카페를 추천합니다.
